# NEXORA v3

Функціональне SaaS-демо.

Нові можливості:
- створення нової заявки;
- пошук і фільтр за джерелом;
- pipeline з трьома етапами;
- швидка зміна статусу;
- картка клієнта;
- відповідальний менеджер;
- коментарі та історія подій;
- KPI pipeline;
- збереження заявок у localStorage браузера;
- адаптація для телефона та ПК.

Це демо без бекенду: дані зберігаються лише у браузері.
