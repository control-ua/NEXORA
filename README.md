# CONTROL AI — Demo

Новий окремий демо-проєкт для перевірки SaaS-ідеї.

## Що всередині
- Головна панель
- AI-контроль заявок
- Заявки у вигляді Kanban
- Об'єкти та прогрес робіт
- Команда та завантаження
- Аналітика
- Адаптивний дизайн під телефон і ПК

## Як запустити
Просто відкрийте `index.html` у браузері.

## GitHub Pages
1. Створіть новий репозиторій.
2. Завантажте всі файли з архіву в корінь репозиторію.
3. Settings → Pages → Deploy from a branch.
4. Branch: `main`, folder: `/root`.
