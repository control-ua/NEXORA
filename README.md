# NEXORA — Client Ready Demo

Фінальна демо-версія перед перевіркою продажів.

Є:
- Dashboard керівника
- NEXORA AI / ризики
- CRM pipeline заявок
- створення заявок
- картка клієнта та історія
- об'єкти, бригади, дедлайни, прогрес
- демо фото до/після
- команда
- завдання та прострочки
- аналітика
- налаштування компанії
- localStorage для демо-даних
- мобільна та desktop версії

Це sales-demo без серверної бази. Наступний етап — перевірка попиту у реальних клієнтів, а не додавання функцій.
