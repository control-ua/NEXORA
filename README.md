# NEXORA PRO — Sales Demo

Расширенная версия демо для показа бизнесу.

Меню:
- Главная
- Входящие
- Заявки
- Клиенты
- Календарь
- Объекты
- Команда
- Задачи
- Финансы
- Документы
- Склад
- Аналитика
- NEXORA AI
- Настройки

Система остается статическим sales-demo: рабочие заявки/объекты/задачи хранятся в localStorage, остальные бизнес-модули показывают продуктовую концепцию.
